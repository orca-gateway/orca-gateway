# Changelog

## 0.1.0 - 2026-05-05

Initial release.

### Added

- `orca plugin add` / `remove` — wire Orca plugins into a project, including native config patches.
- `orca plugin create` — scaffold a new Orca plugin package.
- `orca plugin generate` — regenerate plugin glue code.
- `orca plugin doctor` — validate native and Dart-side plugin wiring.
- `orca plugin build` — build native plugin artifacts.
- Native config patchers for AndroidManifest, Info.plist, Gradle, and Podfile.
